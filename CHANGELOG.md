# Meio Hub

## 1.1.2

- "More Meio addons" suggests Meionomics again: it is ready for everyone. It finds the
  cheapest way to level your professions and the crafts that sell for the most
- Meio Shards' summary matches what it does now: one key deletes the Soul Shards over your
  cap or soul bag, never in combat

## 1.1.1

- "More Meio addons" no longer suggests Meionomics: it is still an early test and not
  ready for everyone yet. If you already have it, it still shows in your list as before

## 1.1.0

- Newer versions: when a guildmate or groupmate with MeioHub has a newer version of one of
  your Meio addons, one chat line says so and its row shows "x.y.z out"
  (`/meiohub versions off` stops it)
- Errors: when one of your Meio addons hits a Lua error, one chat line names it with its
  GitHub issues page, and its row shows how many errors this session
  (`/meiohub errors off` stops it)
- Meio DPS's summary now mentions its numbers on action buttons
