# Meio Hub

The front door to the Meio addons: the ones you have, with their commands, settings and
help, and the ones you could add.

![Before, the game's AddOns list shows four Meio addons by name only; with Meio Hub, each has
its slash command and Settings and Help buttons, and the Meio addons not installed are listed
below with what they do](docs/before-after.png)

## What it does

One window lists every Meio addon you have installed. You don't need to remember a single
slash command.

- Each addon's slash command, and buttons that open its settings or print its help
- Hover a row for what the addon does, all its commands and where its settings are
- Addons you've turned off are shown greyed, with how to turn them back on
- Below them, the Meio addons you don't have yet, with a line on what each does

No settings of its own. The same list is in Esc > Options > AddOns > MeioHub.

- `/meiohub` (or `/mh`) opens or closes the window, also from the minimap addon menu
- `/meiohub reset` puts the window back in the middle
- `/meiohub help` lists the commands

## Install

Use your addon manager (CurseForge, Wago), or unzip a GitHub release into
`World of Warcraft\_forever_\Interface\AddOns` and restart WoW fully.
